## 이전 보호 규칙과 충돌한 범위

최신 사용자 요청이 모션·판정 개선과 원본 보존을 명시적으로 승인했다. 기존 AGENTS의 고정 시퀀스/판정/원본 모션 교체 금지를 이유로 결함을 유지하지 않았다.

- src/game/**, tests/**, tools/mocap/**와 원본 19관절 JSON/FK는 수정하지 않았다.
- candidateRules.ts에 새 판정/패턴, candidateCombatPose.ts에 별도 화면 모션을 추가했다. 앱과 미리보기는 ruleset=candidate를 명시한다. 기존 세션 기본값은 baseline이므로 이전 계약 테스트도 유지된다.
- 기존 투영/FK 값을 조작하지 않고 후보 화면만 수작업 ScreenPose를 사용한다. 따라서 후보 동작은 CMU 기반 실제 복싱 동작의 정확성을 보증하지 않는다.
- P0AttackAttemptController는 후보일 때만 너무 이른 입력 후 240ms 복귀를 허용한다. baseline의 기존 첫 입력 확정은 그대로다. 정상 유효 입력은 공격당 한 동작으로 유지하고 화면에 동작 중임을 표시한다.
- 변형마다 판정 창은 동일하고 결과에 따라 몰래 바뀌지 않는다. 기존 cue/impact/responseWindow 수치는 유지했다. 새 모션은 공통 impact 시각에 접촉점을 맞춘다.
