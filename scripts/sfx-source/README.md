# 타격음 출처

- 작품: Punch
- 제작자: Iwan 'qubodup' Gabovitch
- 원문: https://opengameart.org/content/punch
- 원본: https://opengameart.org/sites/default/files/qubodupPunch.7z
- 라이선스: CC0 (원문 페이지에 표시, 2026-09-15 확인)
- 원 녹음 참조: https://freesound.org/people/qubodup/sounds/53985/

01 FLAC은 피격, 02 FLAC은 가드에 사용합니다. 자르기, 고/저역 필터, 감쇄와 끝 페이드를 적용합니다. 원본은 유지합니다. 회피음은 고정 seed의 필터 잡음으로 생성합니다.

재생성: FFMPEG_PATH 환경변수를 FFmpeg 실행 파일로 지정한 뒤 node scripts/generate-playtest-sfx.mjs. 추가 패키지 설치는 필요 없습니다.
