# 광고 보상·응답 지연 보완 (2026-10-13)

## 변경 내용

- 보상형 광고의 보상과 닫힘을 별도로 기록한다. 닫힘이 먼저 와도 이후 userEarnedReward가 도착하면 재도전을 한 번만 실행한다.
- 닫힘 후 5초 동안 보상 확인 상태를 보여주고, 확인이 지연되면 재시도 버튼을 활성화한다. 5초가 지난 뒤에도 사용자가 새 광고를 준비하거나 화면을 벗어나기 전까지 늦은 보상을 수신한다. 닫힘만으로 보상하지 않는다.
- 보상형·전면형 광고 로드가 15초 동안 응답하지 않으면 재시도 가능한 오류로 전환한다. 이전 로드의 뒤늦은 콜백은 무시한다.
- 광고 표시 후 120초 동안 종료 응답이 없으면 광고를 닫고 돌아와 버튼을 누르라는 안내를 표시한다. 시간 초과만으로 경기를 시작하거나 보상하지 않는다. 사용자가 돌아와 눌렀을 때, 보상형은 확인된 보상이 있는 경우에만 원래 재도전을 실행하며 없으면 광고를 다시 준비한다. 전면형은 다음 난이도로 진행한다.
- 광고 작업별 타이머와 구독을 정리한다. 동기 콜백으로 작업이 먼저 끝난 경우에도 반환된 구독을 해제하며, 이전 광고의 콜백과 중복 완료가 새 경기에 영향을 주지 않게 한다.

실제 광고 화면을 닫는 기능을 추가한 것은 아니다. SDK 반환 함수는 콜백 해제이므로 광고 자체의 닫기 버튼·기기 동작은 실제 토스 앱에서 확인해야 한다. 복구 버튼은 돌아온 게임 화면에서 사용자가 명시적으로 누르는 방식이다.
