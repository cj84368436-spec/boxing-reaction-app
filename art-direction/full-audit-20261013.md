# 전체 오류 점검 및 보완 — 2026-10-13

## 결론

기존 글러브 문제 외에 앱 비활성 상태의 광고 복귀, 응답 없는 기록 읽기 문제를 재현하여 보완했다. 작은 경기 영역에서 대기 글러브가 상대 얼굴을 가리는 문제도 데스크톱 장면으로 확인하여 함께 보완했다. 아래 자동 검사와 번들 검사가 통과했으며, 이번 AIT의 실제 토스 기기 화면·효과음·광고 복귀는 아직 확인하지 않았다. 따라서 출시 가능 또는 모든 오류 제거로 판정하지 않는다.

## 확인한 결점과 수정

| 결점 | 확인 근거 | 보완 |
| --- | --- | --- |
| 대기 손목 잘림, 가드 팔 끝 단절 | 원본 셀에서 흰 손목이 끝나는 지점까지 기존 표시 범위를 계산하고 크기별 장면 확인 | 주먹과 흰 손목은 원래 비율로 표시하고, 손목 아래 팔만 화면 밖으로 이어지게 표시. 원본 PNG 유지 |
| 작은 경기 영역에서 대기 글러브가 얼굴을 가림 | 320×240 장면에서 얼굴 가림 확인 | 양쪽 복서를 같은 배율로 함께 맞춤. 모션·판정·카메라 월드 좌표는 유지하고 화면에 보이는 범위만 조정 |

| 기록 읽기가 응답하지 않으면 시작 버튼이 계속 잠김 | 수정 전 화면 테스트에서 8초 이후에도 시작 불가로 실패 | 8초 후 이번 실행의 기록으로 게임 허용. 저장은 중지해 기존 기록을 보호하고 늦게 도착한 읽기 결과는 무시 |
