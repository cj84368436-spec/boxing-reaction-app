## 출시 전에 해결할 항목

1. **온라인 비교 연결 미완료:** src/pages/index.tsx는 competitionBaseUrl 없이 화면을 연결한다. 앱에서는 개인 기록 조회만 가능하고 오늘의 온라인 코스는 비활성화된다. tools/browser-preview/server.mjs는 127.0.0.1에서만 실행되는 로컬 서버다. 공개 HTTPS 서비스와 앱 연결이 필요하다.
2. **공개 순위의 신뢰성 미확보:** competition-service.mjs는 쿠키별 기록이며 계정별 사람이 아니다. 쿠키를 바꾸면 여러 참가자로 집계될 수 있고, 시작 후 시간을 기다렸다가 정답 입력 시간을 만들어 보내는 행위는 현재 재생 검증으로 구분할 수 없다. 서버 재생은 잘못된 결과 조작을 줄이지만 실제 사람의 플레이를 증명하지 않는다. 파일 저장도 단일 프로세스용이다. 공개 순위에 사용하기 전 참가자 식별·악용 대응·운영 저장소 설계가 필요하다.
3. **출시 아이콘 미지정:** granite.config.ts의 brand.icon이 빈 값이다. 빌드 통과는 아이콘 및 실제 심사 준비 완료를 뜻하지 않는다.
4. **기기 검증 미완료:** 앱인토스 실제 Android/iOS에서 연속 터치·백그라운드 복귀·다섯 번째 피격 종소리·작은 화면·영구 저장을 확인해야 한다. 데스크톱 브라우저나 React Native 단위 테스트로 대체하지 않았다.
