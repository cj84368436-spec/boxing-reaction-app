# 이미지 생성 지시 요약

내장 image_gen 사용. 아래는 생성 당시 지시의 요약이며 원문 전문은 대화 도구 기록에 있다.

- 공통: 독창적인 한국 성인 복서, 짧은 검은 머리, 붉은 글러브, 초록 반바지와 아이보리 허리띠. 단순한 셀 채색 만화풍, 굵은 윤곽선, 같은 인물과 색상 유지.
- jab / straight / hook: 투명 배경, 3열 2행, 준비·예비·뻗기·접촉·회수·준비의 6자세. 정면 상대 복서 시점, 허벅지까지, 각 공격의 손과 궤적 구분.
- coach: 회색 머리와 콧수염의 관장, 검은 티셔츠와 크림 수건. 3열 1행, 얄미운 미소·관심·놀람, 투명 배경.
- gloves: 플레이어 1인칭 파란 글러브 한 쌍, 2열 1행, 투명 배경.
- gym: 세로형 오래된 청록색 동네 복싱 체육관, 따뜻한 조명, 링과 로프, 중앙에 인물을 배치할 공간.

별도 파일의 셀을 SVG viewBox로 표시하며 PNG를 잘라 재저장하지 않는다.
