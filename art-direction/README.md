# 만화풍 플레이 후보 — 2026-09-17

사용자가 선택한 방향: 더 만화적으로 단순화. 기존 출시 후보를 별도 폴더에 복사해 표현만 재구성했다.

## 실행

이 폴더에서 node tools/browser-preview/server.mjs 실행. 현재 확인한 주소: http://127.0.0.1:3000/?seed=123 . 개발용 브라우저이며 실제 토스 런타임 검증을 대신하지 않는다.

## 변경

복서의 잽·스트레이트·훅을 각 6칸 스프라이트로 표시하고, 기존 공격 시각에 맞춰 준비·뻗기·접촉·회수를 선택한다. 관장 3표정, 플레이어 파란 글러브, 체육관 배경을 같은 만화풍으로 적용했다. 스트레이트 준비 셀의 손 위치 오류는 해당 셀 대신 기본 자세 회전으로 처리했다.
