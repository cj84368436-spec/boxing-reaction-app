# 만화풍 생존 경기 통합 — 2026-09-20

## 적용한 기능

- 관장: 좁은 어깨·가는 팔·긴 얼굴의 새 마른 만화 캐릭터. 비웃음·관심·당황 3표정. 생성 원본을 보존하고 src/app/assets/art/coach-skinny.png로 저장했다. 내장 image_gen 사용. 정확한 생성 프롬프트는 skinny-coach-prompt.md.
- 한 판 30회 공격, 목숨 5개. 다섯 번째 피격 순간 종료하고 기존 3타 종소리. 끝까지 살아남으면 클리어.
- 입문 0.65배 / 도전자 1배 / 챔피언 1.12배. 10회씩 단발 중심에서 연타 중심으로 발전한다. 기준 엔진의 판정 창과 모션 데이터는 수정하지 않았다.
- 승급: 30회 클리어 + 완벽 회피 24회 이상 + 목숨 3개 이상. 해금은 저장되고 이전 난이도도 다시 선택할 수 있다.
- 난이도별 최고 기록·최장 연속 완벽 회피. 비교 기준: 클리어 여부 → 생존 수 → 남은 목숨 → 완벽 회피 → 평균 유효 회피 반응 시간. 실패한 마지막 주먹은 생존 수에 포함하지 않는다. 브라우저 localStorage / 앱 AsyncStorage에 저장한다. 저장 실패는 알리고 플레이는 계속 허용한다.
- 기존 37개 관장 대사와 구체적 실패 이유를 유지한다. 재도전 버튼은 다시 도전이다.
- 오늘의 동일 코스: 같은 날짜(KST)의 고정된 도전자 난이도/순서. 서버가 제출한 입력을 다시 재생해 결과를 계산하며 클라이언트의 점수를 믿지 않는다. 브라우저 익명 식별자별 최고 기록 하나만 집계한다. 사람 수로 표현하지 않고 참가 기록 수로 표시한다. 20개 미만이면 백분율을 숨긴다. 동점의 백분율은 동점군 전체를 포함한다.

## 현재 비교 기능의 경계

미리보기의 실제 API는 이 PC의 루프백 서버에만 열려 있다. 공개 배포하지 않았으므로 다른 기기의 실제 이용자 모집/전국 순위는 아직 아니다. 실제 데이터가 없으면 비교 상대 대기로 표시한다. 앱의 competitionBaseUrl은 공개 서버 연결 전이므로 온라인 버튼이 비활성이다. 앱에도 연결용 클라이언트와 결과 표시가 구현되어 있다.

서버의 익명 식별은 브라우저 쿠키 단위다. 별도 브라우저/기기 중복 참여나 자동 입력을 완전히 차단하는 본인 인증/봇 방지 시스템은 아니다. 공개 경쟁 서비스에는 호스팅·HTTPS·운영 저장소·참가자 식별/남용 방지 정책을 정해 연결해야 한다. 임의 백분위나 가짜 참가자를 표시하지 않았다.

## 검증

- 최종 엔진47 + 앱116 + 미리보기/비교 서버10 = 173개 검사 통과.
- 앱 타입 검사 및 Android/iOS 앱 빌드 통과.
- Edge 390×844 / 320×568에서 3단계 실제 30회 완주, 2회 승급, 재접속 후 해금 유지, 실패 후 최고 기록 보존 확인.
- 별도 테스트 서버의 두 참가 기록으로 1위/2위 계산 확인. 테스트 기록은 임시 디렉터리에 격리하여 실제 local-data와 섞이지 않았다.
- 서버는 소유하지 않은 코스, 비정상/역순 입력, 너무 이른 완료, 과다 입력을 거부. 재제출 중복 방지와 파일 저장 후 서버 재시작 시 기록 유지 검사 통과.
- 작은 화면에서 관장 소개 잘림 수정 후 실제 화면과 버튼 접근 확인.
- 원본 출시 후보 src 69개, 보호된 엔진/기준 테스트/모션 도구32개 보존.
- 실제 휴대폰 터치·음향·토스 런타임 QA는 아직 필요하다. 난이도와 승급 문턱은 실제 플레이 데이터로 조정할 초기값이다.
